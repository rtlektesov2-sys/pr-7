# FORMA — каталог онлайн-курсов

Сайт на Node.js, Express и EJS. На сервере формируются страницы каталога, отдельного курса, информации о платформе и ошибки 404. Курсы хранятся в облачной MongoDB Atlas; поиск, фильтр и API работают с коллекцией `courses`.

## Структура

- `server.js` — настройка Express, EJS, маршруты сайта и API.
- `db.js` — подключение к MongoDB Atlas.
- `migrate-data.js` — однократный перенос курсов из локального `data.json` в MongoDB.
- `enrollments.json` — заявки на курсы.
- `feedback.json` — сообщения из формы обратной связи.
- `views/index.ejs` — список курсов и пустое состояние.
- `views/feedback.ejs` — форма обратной связи и ошибки валидации.
- `views/film.ejs` — подробная страница курса (`/film/:id`, имя оставлено по условию задания).
- `views/about.ejs` — информационная страница.
- `views/404.ejs` — страница ненайденного маршрута.
- `views/partials/head.ejs`, `header.ejs`, `footer.ejs`, `card.ejs` — повторно используемые блоки.
- `public/css/style.css`, `public/js/app.js` — стили и обработчик формы добавления.
- `public/img/`, `public/fonts/` — локальные изображения и шрифты.

## Запуск

1. Создайте бесплатный кластер MongoDB Atlas и пользователя базы данных. В настройках Network Access разрешите подключение с вашего IP-адреса.
2. Создайте локальный `.env` и укажите строку подключения Atlas:

```dotenv
MONGODB_URI=mongodb+srv://USERNAME:PASSWORD@CLUSTER_HOST/cinema?retryWrites=true&w=majority
```

Файл `.env` не добавляйте в Git. Курсы хранятся в облачной базе `cinema`, коллекции `courses`; `data.json` в репозитории отсутствует. Скрипт `npm run migrate` нужен только при наличии локального `data.json` для переноса.
3. Установите зависимости и запустите сайт:

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. Если порт занят, в PowerShell задайте другой:

```powershell
$env:PORT = "3001"; npm start
```

## Страницы и проверка

| Запрос | Ожидаемый код | Получен при проверке | Результат |
| --- | ---: | ---: | --- |
| `GET /` | 200 | 200 | Список курсов, общий header/footer и карточки |
| `GET /film/1` | 200 | 200 | Подробная страница курса №1 |
| `GET /film/999` | 404 | 404 | Общая EJS-страница ошибки |
| `GET /about` | 200 | 200 | Страница о платформе с общими блоками |
| `GET /feedback` | 200 | 200 | Форма обратной связи |
| ` /feedback` | 303 | 303 | Валидация и сохранение обращения в `feedback.json` |
| `GET /qwerty` | 404 | 404 | Та же EJS-страница ошибки |
| `GET /?q=not-a-course` | 200 | 200 | Сообщение «Записей пока нет» |
| `GET /css/style.css` | 200 | 200 | Файл стилей |
| `GET /js/app.js` | 200 | 200 | Клиентский JavaScript |

Пустое состояние списка отображается, если коллекция `courses` в MongoDB пуста.

## API

| Запрос | Получен при проверке | Результат |
| --- | ---: | --- |
| `GET /api/items` | 200 | Все 8 курсов |
| `GET /api/items?category=Программирование` | 200 | 3 курса выбранной категории |
| `GET /api/items/1` | 200 | Один курс |
| `GET /api/items/999` | 404 | JSON-ошибка |
| `POST /api/items` с непустым `title` | 201 | Новый курс с ID 9 (тестовая запись удалена) |
| `POST /api/items` без `title` | 400 | JSON с ошибкой валидации |
| `POST /film/9/enroll` с корректными данными | 303 | Перенаправление на страницу курса с подтверждением (тестовая заявка удалена) |

Минимальный JSON для добавления записи по заданию: `{"title":"Курс по JavaScript"}`. Дополнительные поля курса заполняются сервером значениями по умолчанию; форма преподавателя отправляет расширенный объект.

Заявки и сообщения обратной связи по-прежнему сохраняются в `enrollments.json` и `feedback.json`. Это учебный пример без входа и паролей; API добавления курсов не защищён правами преподавателя. Не используйте реальные персональные данные в публично размещённой версии.
